# 大肥鱼·圣经原句出处

MaiBot QQ 群聊回复的本地圣经原句标注插件。回复中出现《新标点和合本（简体）》的连续原文时，在同一条消息下方追加经卷、章、节。

```text
日光之下并无新事。
--出自（传道书 1:9）
```

运行时不联网、不调用模型、不保存聊天正文，无需 API Key。经文随插件分发，首次加载构建内存索引。

## 安装

需要 MaiBot **1.3.17–1.3.x**、插件 SDK **2.19.x**。已在 MaiBot 1.3.17 / SDK 2.19.0 上验证加载与运行中自检；其他宿主版本尚未测试。

- 插件市场收录后，可在 WebUI 搜索“大肥鱼·圣经原句出处”安装，再到插件管理启用。
- 也可在 WebUI 的 Git 仓库安装入口填写 `https://github.com/CODao/maibot-bible-citation`。
- 或下载 [Releases](https://github.com/CODao/maibot-bible-citation/releases) 的 ZIP，经 WebUI 的 ZIP 安装入口安装。

首次安装后按宿主提示重启。运行配置由 SDK 自动生成，仓库不提交 `config.toml`；示例见 [config.example.toml](config.example.toml)。

运行时 ID 保持 `local.bible-citation`，以兼容此插件早期本机版本。不要同时安装、启用另一份相同功能的副本。

## 匹配规则

- 默认**部分命中**即可：回复中有连续文字与同一节经文逐字相同，就追加出处。
- 默认至少连续 **5 字**，字数忽略标点和空格。整条回复不足 5 字时，必须完整命中该短回复，例如“给我水喝”（4 字）和“要有光”（3 字）。
- 查询副本忽略逗号句号以外的标点、空格和英文大小写，使用 Unicode NFKC 规范化。不会替换同义词、改字、做语义相似匹配或自动转换简繁体。
- 默认最多 1 个出处：优先最长命中片段；同长度时优先贴近经节首尾，再按经卷顺序选择。同一短语可能出现在多节经文中，显示的出处不保证唯一。
- 出处只表示文字一致，**不表示回复表达了经文原有的语境或立场**。普通日常用语也可能命中，特别是很短的回复。
- 默认只处理 QQ 群聊，可选择也处理 QQ 私聊。其他平台、通知和命令不处理。
- 只查询实际发送的文字段，不查询被引用群友的消息、图片 OCR、表情描述、历史消息或模型思考。代码块、网址本身和跨图片等媒体边界拼接的文字不作为匹配内容；不跨经节拼凑。
- 已带 `--出自（…）` 的消息不重复追加。超过 16,000 字符的回复跳过经文查询。

## 标点只参与匹配预处理

只在用于查经的文字副本中清理标点：保留中英文逗号和句号作为边界，同类中英文标点统一比较；其他标点、空格仅在这个副本中忽略。

**实际发送的回复完整保留，包括问号、感叹号、引号、括号、Markdown、网址和换行。** 命中时只在原回复下面追加出处。没有命中、只有标点的回复也保持原样，不截断或取消发送。

原有图片、@、引用及路由信息保持原样。异常或超时按宿主的跳过策略继续原发送链路。

## 配置

在插件管理中启用“大肥鱼·圣经原句出处”，编辑插件设置。

| 设置 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 插件功能总开关 |
| `group_only` | `true` | 仅 QQ 群聊；关闭后也处理 QQ 私聊 |
| `min_chars` | `5` | 连续命中最少字数；整条回复更短时按实际长度匹配 |
| `partial_match` | `true` | 连续片段命中即可；关闭后恢复完整回复/完整句子匹配 |
| `match_sentences` | `true` | 仅在部分匹配关闭时生效：也检查完整句子 |
| `max_references` | `1` | 每条最多 1–3 个出处 |

状态页的“本机自检（不向群发消息）”会检查匹配、5 字门槛、短回复例外及标点过滤，不向聊天群发送消息。处理计数含自检，重启后清零。

停用插件即可停止标注。插件不修改人格、接话频率或长期记忆设置，仅对新发送的消息生效。

## 数据与许可

经文来自 [eBible.org 简体和合本 cmn-cu89s](https://ebible.org/bible/details.php?id=cmn-cu89s)，来源声明 **Public Domain**。数据包含 66 卷、31,021 条 VPL 记录；保留原文与原有经节编号，不补入其他译本的编号或文字。

原始下载、来源记录与 SHA-256 校验值见 [assets/source.json](assets/source.json)。经文资源位于 `assets/`，与用户持久数据目录分开。插件校验随包数据摘要后再加载。

代码使用 [MIT License](LICENSE)，经文按其公有领域声明单独分发。

## 开发与验证

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

测试覆盖经文命中、部分匹配、短回复门槛、同义改写不算原句、跨节/跨媒体边界、重复标注、回复正文与标点保留、发送参数保留、SDK 处理器及自检等。

本地曾观察到真实 QQ 发送前 Hook 接收回复；当前版本已验证宿主加载和运行中自检。公开版本未额外向真实 QQ 群发送消息进行显示验收，不把自检结果视作 QQ 客户端最终送达证明。
